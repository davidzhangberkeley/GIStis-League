# GIStis-League
Open Project, Spring 2026

To set up your repository & branch (ONLY DO THIS ONCE): 
```bash
git clone https://github.com/davidzhangberkeley/GIStis-League.git
git switch -c <YOUR_NAME_HERE>
```

To commit & push local changes onto the github (through your branch):
```bash
git branch <YOUR_NAME_HERE>
git add .
git commit -m "<YOUR_COMMIT_MESSAGE_HERE>"
git push origin <YOUR_NAME_HERE>
```

To make a pull request, go to pull requests in github, and select "Create Pull Request". This will be verified/denied by David and Emily.
